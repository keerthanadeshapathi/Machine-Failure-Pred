# Machine Failure Prediction Using Machine Learning
## Project Aim
The aim of this project is to predict machine failures using machine learning based on machine operating conditions. It helps identify possible failures in advance and supports predictive maintenance.
## Dataset
AI4I 2020 Predictive Maintenance Dataset.
## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- FastAPI
- Streamlit
## Machine Learning Algorithm
- Decision Tree Classifier
## Project Workflow
1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. Data Preprocessing
5. Model Training
6. Model Evaluation
7. Hyperparameter Tuning
8. Model Deployment
## Deployment
The trained model is deployed using FastAPI and Streamlit.
## Project Files
- app.py – Streamlit application
- main.py – FastAPI application
- train_model.py – Model training
- machine_failure_model.pkl – Saved ML model
- model_columns.pkl – Saved feature columns
## Output
Predicts whether a machine is likely to fail (0 = No Failure, 1 = Failure).
